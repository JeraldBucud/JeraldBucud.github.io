## Presentation decisions

- Lead with Java, Spring Boot, React and PostgreSQL as the primary full-stack direction.
- Keep Python, computer vision, JavaFX and Jakarta EE visible through the projects that demonstrate them rather than the main profile identity.
- Keep the SmartTech Maven build badge because it links to a real GitHub Actions workflow and communicates a verifiable build check.
- Keep the functional Google Colab badge in the YOLOv11 repository because it opens the notebook directly.
- Avoid GitHub statistics, contribution-streak graphics, visitor counters, animated typing banners and decorative skill-icon walls.
- Use `Master of Information Technology candidate`, `graduate and junior full-stack roles`, and project-specific contribution wording rather than titles that imply unverified commercial seniority.
- Keep `JeraldBucud.github.io/README.md` focused on the portfolio repository, its projects, technologies, structure and content boundaries.
